## Project Overview
This project uses Machine Learning techniques to segment 200 mall customers based on Age, Annual Income and Spending Score.
It compares three clustering algorithms and seven supervised classification algorithms.

## Dataset
Mall Customers Dataset containing 200 customer records.

## Algorithms Implemented
### Clustering
1. K-Means
2. Agglomerative Clustering
3. DBSCAN

### Classification
4. Logistic Regression
5. Decision Tree
6. Random Forest
7. K-Nearest Neighbors
8. Support Vector Machine
9. Gaussian Naive Bayes
10. Multi-Layer Perceptron

## Project Results
- K-Means achieved a silhouette score of 0.4166.
- Five customer segments were identified.
- Logistic Regression achieved 97.5% cross-validation accuracy.
- Seven classifiers were evaluated.
